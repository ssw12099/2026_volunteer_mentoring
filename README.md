# 2026 초등학생 C언어 멘토링

초등학생을 대상으로 C언어 멘토링 봉사를 진행하며, 배운 문법을 작은 게임에 적용할 수 있도록 수업과 실습을 구성합니다. 
이 저장소는 주차별 자료와 수업 설계 과정을 모은 멘토링 포트폴리오입니다.

## 수업은 이렇게 진행합니다

Zoom으로 주 1회, 두 교시 수업을 진행합니다. 제가 화면을 공유하고 학생과 PPT를 함께 봅니다. 예제와 실습 문제를 만나면 학생이 화면에 나온 코드를 [Programiz C Online Compiler](https://www.programiz.com/c-programming/online-compiler/)에 직접 입력해 실행합니다.

코드가 길면 제가 Zoom 채팅에 코드 전체를 보내고, 학생은 복사해서 컴파일러에 붙여넣습니다. 웹 컴파일러에서 파일을 여는 데 어려움이 있어, 수업에서는 코드 입력이나 복사·붙여넣기로 바로 실행할 수 있게 안내합니다.

## 최신 작업 · 9주차

배열을 자동차별 이동 거리를 저장하는 칸막이 보관함에 비유하고, 배운 내용을 **부스터 레이스**에 적용하는 수업을 준비했습니다. 그림으로 자동차 번호와 배열 칸 번호를 구분한 뒤, 실습에서 전체 자동차를 움직이고 선택한 차의 거리만 바꿔 봅니다. 자료는 PPT 18장, 이론 예제 2개, 단계별 문제·정답 4쌍, 완성 게임으로 구성했습니다.
