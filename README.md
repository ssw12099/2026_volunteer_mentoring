## 실습 방법

[Programiz C Online Compiler](https://www.programiz.com/c-programming/online-compiler/)에 해당 단계의 `.c` 파일 내용을 붙여넣고 실행한다. 부스터 레이스는 `01_try.c`부터 시작한다. `*_answer.c`에는 단계별 정답이, `race_final.c`에는 완성 게임이 들어 있다.
