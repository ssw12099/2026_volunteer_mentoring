# 2026 초등학생 C언어 멘토링

한림대학교에서 빅데이터를 전공하는 소선웅입니다. 초등학생을 대상으로 C언어 멘토링 봉사를 진행하며, 배운 문법을 작은 게임에 적용할 수 있도록 수업과 실습을 구성합니다. 이 저장소는 주차별 자료와 수업 설계 과정을 모은 멘토링 포트폴리오입니다.

## 수업은 이렇게 진행합니다

Zoom으로 주 1회 진행하며, 일정에 따라 조율합니다. 한 회차는 2교시로, 실제 수업 시간은 교시당 약 35분입니다. 1교시에는 그림과 예제로 개념을 설명하고, 2교시에는 완성 게임을 시연한 뒤 학생이 코드를 직접 바꾸고 실행합니다.

실습은 빈칸 채우기에서 시작해 한 줄을 직접 쓰고, 마지막에는 작은 기능을 완성하는 순서로 진행합니다. 학생이 먼저 시도한 다음 정답과 실행 화면을 확인할 수 있도록 PPT와 단계별 코드를 구성합니다.

## 최신 작업 · 9주차

배열을 자동차별 이동 거리를 저장하는 칸막이 보관함에 비유하고, 배운 내용을 **부스터 레이스**에 적용하는 수업을 준비했습니다. 그림으로 자동차 번호와 배열 칸 번호를 구분한 뒤, 실습에서 전체 자동차를 움직이고 선택한 차의 거리만 바꿔 봅니다. 자료는 PPT 18장, 이론 예제 2개, 단계별 문제·정답 4쌍, 완성 게임으로 구성했습니다.

[Programiz C Online Compiler](https://www.programiz.com/c-programming/online-compiler/)에 해당 단계의 `.c` 파일 내용을 붙여넣고 실행한다. 부스터 레이스는 `01_try.c`부터 시작한다. `*_answer.c`에는 단계별 정답이, `race_final.c`에는 완성 게임이 들어 있다.
