# 2026 초등학생 C언어 멘토링

초등학생을 대상으로 C언어 멘토링 봉사를 진행합니다. 변수, 조건문, 반복문, 배열을 작은 게임에 적용해 봅니다.

이 저장소는 주차별 수업 자료와 수업을 어떻게 설계했는지 보여주는 멘토링 포트폴리오입니다.

## 수업 진행 방식

Zoom으로 주 1회, 두 교시 수업을 진행합니다. 제가 PPT를 화면 공유하고 학생과 한 장씩 함께 봅니다.

- **개념 설명** · 그림과 짧은 예제로 개념을 설명합니다.
- **실습** · 학생이 PPT의 예제와 실습 코드를 [Programiz C Online Compiler](https://www.programiz.com/c-programming/online-compiler/)에 직접 입력해 실행합니다.
- **긴 코드** · 제가 PPT에서 코드를 복사해 Zoom 채팅으로 보내면 학생이 컴파일러에 붙여넣고 실습을 이어갑니다.

수업에 필요한 예제와 실습 코드는 PPT 한 벌에 담습니다. 문제를 풀어 본 뒤에는 다음 슬라이드의 정답과 실행 결과를 함께 확인합니다.

## 9주차 · 배열과 부스터 레이스

배열을 자동차마다 이동 거리를 기록하는 칸막이 보관함에 비유한 수업을 준비했습니다. 먼저 그림으로 자동차 번호와 배열 칸 번호를 구분합니다.

실습에서는 반복문으로 모든 자동차의 거리를 바꾸고, 선택한 자동차에만 부스터를 주는 코드를 작성합니다. 개념 설명부터 단계별 문제와 정답까지 18장에 담았습니다.
